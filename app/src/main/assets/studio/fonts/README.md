# Bundled fonts

Downloaded from Google Fonts by `tools/fetch-fonts.mjs` and served locally
so the Visualiser Studio works offline.

Families: Inter, Roboto, Open Sans, Lato, Montserrat, Poppins, Oswald,
Raleway, Nunito, Playfair Display, plus DSEG7 Classic (segmented LED digits
for the Winamp time display, from the `dseg` npm package, `fonts/vendor.css`).
